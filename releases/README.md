# 📦 Shotput Releases

This directory contains all official releases of the Shotput Blender addon.

## 📋 Release Structure

Each release includes:
- **Release Notes** (`RELEASE-vX.X.X.md`) - Detailed changelog and features
- **Addon Package** (`shotput-vX.X.X.zip`) - Ready-to-install Blender addon

## 🔄 Current Releases

### v1.0.1 - "The Studio Edition" (Latest)
- **Release Date**: August 20, 2025
- **Blender Compatibility**: 4.4.0+
- **Package**: `shotput-v1.0.1.zip` (138KB)
- **Notes**: `RELEASE-v1.0.1.md`

#### Key Features:
- Smart File Output Node Creation
- Intelligent Version Management  
- Visual Node Organization
- Lazy Hook-Up System
- Preset System with JSON support

## 📥 Installation

1. Download the latest `.zip` file from this folder
2. In Blender: **Edit** → **Preferences** → **Add-ons** → **Install...**
3. Select the downloaded zip file
4. Enable "Shotput" addon

## 📦 **Installation**

1. Download `shotput-vX.X.X.zip`
2. In Blender: **Edit** → **Preferences** → **Add-ons** → **Install...**
3. Select the downloaded zip file
4. Enable "Shotput" addon
5. Find the panel in **Compositor** workspace → **Sidebar** → **Shotput** tab
